# Adaptations

Stories under **Foundations**, **Components**, and **Page Templates** are loaded from the Virginia Design System checkout (`VDS_ROOT`). Pull that repo to pick up new upstream stories and CSS. This folder does not copy them.

Add a story in `stories/` here when you are trying a change that is not upstream yet. When it is ready, move that story into the design-system repo’s `stories/` directory so the next checkout includes it.
